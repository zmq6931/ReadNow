# ReadNow

Windows 划词 / 截图朗读小工具（C# WPF，.NET 8）。单文件绿色 exe，常驻系统托盘。

## 功能

- **划词朗读**：鼠标划选文字 → 光标旁弹出小窗 → 一键朗读；`Ctrl+A` 全选同样触发，支持最长 20 万字的长文档
- **神经网络语音**：在线神经语音，音质自然（豆包同款 Edge 语音引擎）
  - 声音下拉框：**晓晓**（标准普通话女声，默认）/ **晓曼**（粤语+英语·港味女声），选择自动记忆
  - 英文句子自动由 **Aria**（美式英语女声）朗读，数字、金额、百分比原生英文念法
  - 已下载 Windows 本地自然语音包时自动离线使用（设置 → 辅助功能 → 讲述人 → 添加自然语音），零网络延迟
  - 在线合成偶发失败时自动换连接重试；仍失败（如断网）才回退系统离线语音，且优先回退同语言声音（晓曼→粤语系统音，不会突然变普通话）
- **极速出声**：弹窗出现即后台预合成（双声音前三句）+ 3 条连接预热池 + 播放时三句流水线并行合成；朗读中备选声音同步预取，**中途切换声音零等待**
- **键盘流操作**：弹窗弹出即聚焦「朗读」按钮——空格/回车播放暂停，`Esc` 停止关闭；拖完倍速滑块焦点自动回到朗读键
- **精确暂停续播**：暂停即冻结在当前发音位置，继续时一词不差；停止记住位置；朗读中切换声音从当前位置无缝续播（进度比例定位，不回句首）
- **倍速滑块**：0.5x ~ 4.0x，播放器实时变速（带音调校正，不变尖、零延迟、位置不动），设置全局记忆
- **一键复制**：弹窗内「📋 复制」按钮，把识别/选取的全部文字复制到剪贴板
- **中英互译**：弹窗内一键翻译（Google / MyMemory 双通道，需联网）
- **截图朗读**：
  - `Alt+Q` 内置区域截图（微信式冻结多屏画面 → 框选 → OCR → 弹窗）
  - `Win+Shift+S`、微信 `Alt+A` 等截图进剪贴板后自动识别
  - `Ctrl+Alt+R` 手动识别剪贴板截图
  - OCR 结果自动清洗（去掉逐字空格/碎行），朗读不卡顿
- **功能开关三件套**：弹窗内复选框与托盘菜单双向同步、重启保留——划词朗读 / 截图识别 / 开机自动启动（注册表 Run 键）
- **托盘找回界面**：右键托盘图标 →「显示界面」，或双击图标，随时重新弹出主界面（Esc 关窗、开关全关也不怕找不到）
- **单实例运行**：重复启动自动拦截；操作均有托盘气泡反馈

## 技术要点

- TTS：Edge 大声朗读在线接口（WebSocket + Sec-MS-GEC v2 令牌，协议自实现）；本地兜底 Windows.Media.SpeechSynthesis
- 播放：Windows.Media.Playback.MediaPlayer（PlaybackRate 实时变速带音调校正，精确暂停）
- 性能：弹窗预合成 + 3 条 WebSocket 连接预热池 + 深度预取流水线 + 备选声音随播预取
- OCR：Windows.Media.Ocr（系统内置，离线，中英文混排）+ 文本清洗
- 全局钩子：WH_MOUSE_LL 划词检测 + WH_KEYBOARD_LL `Ctrl+A` 检测
- 焦点抢占：AttachThreadInput 借道前台线程，保证弹窗弹出即可键盘操作
- 设置持久化：`%APPDATA%\ReadNow\settings.json`；异常日志：`%APPDATA%\ReadNow\error.log`

## 运行

下载 [Releases](../../releases) 里的 `ReadNow.exe` 双击即用（需 Windows 10/11 + .NET 8 桌面运行时）。
在线语音需要联网；断网时自动使用系统离线语音。

## 构建

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

## 已知限制

- 在线神经语音需要联网，且依赖 Edge 公开接口（接口变动需适配）
- 在以管理员身份运行的窗口中划词无法取词（Windows 权限隔离）
- 内置框选截图基于冻结画面，多屏 DPI 不一致时裁剪位置可能略有偏差
- 部分截图工具（如微信）放入剪贴板的图片格式特殊，自动识别可能失败，可用 `Alt+Q` 替代
